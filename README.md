The purpose of this project is to analyze employee data to obtain information about an organization's workforce and find helpful suggestions for HR. The analysis involves employee data such as age, gender, ethnicity, department, work location and date of employment. To obtain data in a more visual way, an interactive dashboard with main KPI, graphs, and charts has been created with the help of Power BI. The dashboard shows data about the workforce structure, employee distribution, and hiring tendencies during the years. Based on the results, the project gives some suggestions on how to improve recruitment planning, workforce diversity and management. This project demonstrates that data analysis and visualizations allow an organization to understand the workforce better and make more data-driven HR decisions.
